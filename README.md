# OBS Studio 定制版 —— 区域录制增强 + 录制后自动清理

[English README](README.en.md)

本项目基于 [OBS Studio](https://obsproject.com) master 分支定制，新增了**绘制区域录制**、**画布跟随场景**、**悬浮球快捷录制**、**录制后自动清理**四个主要功能。

---

## 功能一：绘制区域源（Draw Region）

一种新的采集源类型（插件：`win-capture`)，可采集屏幕上的**任意矩形区域**，基于 DXGI 桌面复制实现。

### 使用方法

1. 在"来源"面板点 `+`，选择 **绘制区域**。
2. 在属性窗口中点击 **选择区域...**，全屏框选界面出现，按住鼠标左键拖出要录制的区域（右键或 Esc 取消）。
3. 框选后自动生效：
   - 若该场景**只有区域源一个视频源**，画布和输出分辨率立即变为所选区域大小，源铺满画布（**无需重启**）；
   - 若场景里**还有其它视频源**（整块屏幕采集、摄像头、图片、嵌套场景等），区域源按**原始像素 1:1 叠加并居中**，画布保持主画面大小不变——区域只是叠在主画面上的一个图层；
   - 自动向当前场景补一个 **桌面声音** 采集源（默认音频输出设备，若场景中不存在）——着急录制时不用手动加声音。
4. 也可以手动修改属性里的 X/Y/宽度/高度，然后点 **应用为输出尺寸**，强制把输出设为当前区域大小（无论场景里是否有其它源，同样会自动补桌面声音）。

### 属性说明

| 属性 | 说明 |
| --- | --- |
| 显示器 | 区域所在的显示器 |
| X / Y / 宽度 / 高度 | 区域坐标（相对所选显示器） |
| 选择区域... | 全屏拖拽框选 |
| 应用为输出尺寸 | 把输出分辨率设为当前区域大小 |
| 采集光标 | 是否在画面中显示鼠标 |
| 强制 SDR | HDR 显示器强制按 SDR 采集 |

输出尺寸会按编码器要求自动对齐：宽度向下取 4 的倍数、高度取偶数、最小 32×32。

## 功能二：画布跟随场景

画布（输出）分辨率会**自动跟随当前场景**：

- 切换到**只包含一个"绘制区域"源**的场景 → 画布自动变为该源的区域大小；
- 区域源与其它视频源同处一个场景时 → 区域只是叠加层，**不改变画布**（画布由主画面源决定）；
- 切换到不含区域源的场景 → 画布自动恢复为原来的分辨率。

细节：

- 跟踪状态保存在用户配置中，重启 OBS 也能正确恢复；
- 正在录制/推流/回放缓存/虚拟摄像头时不会改变分辨率，录制停止后自动重新评估；
- 切换配置文件（Profile）时自动重置跟踪状态，不会把别的配置文件的分辨率"恢复"进来；
- 区域源的场景项在区域画布下始终 1:1 铺满（已处理相对/绝对坐标系下的缩放时机问题）。

## 功能三：悬浮球

一个置顶的小悬浮窗，随时随地快速控制录制。

### 开关

**设置 → 通用 → 悬浮窗 → 启用**。勾选后立即显示；也可通过悬浮球右键菜单"隐藏悬浮窗"关闭。

悬浮球是无父窗口的工具窗口，若被系统自行隐藏（资源管理器重启、最小化到托盘、模态对话框等），或因显示器拓扑变化跑到屏幕之外，程序会每秒自检一次：启用状态下自动重新显示，并把位置夹回当前屏幕的可见区域。

### 悬浮球本身

- **拖动**：移动位置（位置会被记住）；
- **单击**：开始 / 停止录制；
- 空闲时显示 `REC`，录制中变红并**显示录制时长**（与主界面状态栏一致，暂停录制时计时冻结）。

### 右键菜单

| 菜单项 | 说明 |
| --- | --- |
| 开始/停止录制 | 同单击 |
| 绘制区域 | 区域录制（见下） |
| 选择场景 | 切换当前场景（普通场景仍在主界面里管理） |
| 隐藏悬浮窗 | 关闭悬浮球（可在设置中重新开启） |

### 绘制区域录制流程

1. 右键悬浮球 → **绘制区域**，全屏框选初始区域；
2. 出现**可调整区域框**：
   - 按住框内任意位置**拖动**移动；
   - 拖动四角/四边（或边框线附近 ±10px 内）**拉伸**大小；
   - 底部工具栏实时显示尺寸，含"开始录制 / 取消"按钮，Esc 取消；
3. 点 **开始录制** 后自动：
   - 创建临时场景（含区域源和默认桌面声音）；
   - 画布/输出变为区域大小；
   - 在区域**外侧**显示红色边界线（不会被录进视频）；
   - 开始录制。
4. 停止录制后自动：切回原场景、删除临时场景、画布恢复。

异常处理：录制启动失败会自动清理；OBS 中途关闭时，下次启动自动清理残留临时场景并恢复画布。

## 功能四：录制后自动清理

**工具 → 录制后自动清理**，录制停止后自动删除不需要的文件。

### 两个独立功能

| 功能 | 说明 |
| --- | --- |
| 删除短视频 | 录制时长低于阈值（默认 10 秒）的录制文件自动删除 |
| 自动删除原格式文件 | 开启自动封装（Auto Remux）后，封装完成后删除原始格式文件，仅保留 MP4 |

### 短视频判断

录制开始/停止时通过前端事件计算时长（暂停录制的时间不计入），低于阈值则判定为短视频并删除。

### 自动封装联动

代码会复刻 OBS 自带的自动封装判定，只在确实会生成封装文件时才等待并删除原文件：

- 高级输出的 FFmpeg 自定义输出、无损 AVI → OBS 不封装，保留原文件；
- fragmented MP4/MOV → 输出为 `<原名>.remuxed.<原后缀>`；
- ProRes 编码器 → 输出为 `.mov`；
- 其它情况 → 输出为同名 `.mp4`。

轮询目标文件，直到其大小连续两次不再变化（封装真正写完）再删除原文件；最长等待 10 分钟，超时则**保留原始录制**并记录告警，不会误删唯一的文件。录制格式本身就是 MP4（封装路径等于原文件）时也会跳过删除。

### 删除策略

- 短视频：原始文件和封装产物都带重试删除（最多 15 次，每次间隔 2 秒）；
- 原格式文件：封装完成后带重试删除（最多 30 次，每次间隔 2 秒），以应对文件占用延迟；
- 全部删除在后台计时器中进行，停止录制时不会卡住界面。

### 实现文件

| 文件 | 说明 |
| --- | --- |
| `plugins/frontend-tools/auto-cleanup.{hpp,cpp}` | 自动清理核心逻辑 |
| `plugins/frontend-tools/auto-cleanup-dialog.{hpp,cpp}` | 设置对话框 UI |

## 构建

与原版 OBS 相同（CMake 预设）：

```powershell
cmake --preset windows-x64
cmake --build build_x64 --config RelWithDebInfo
```

产物：`build_x64/rundir/RelWithDebInfo/bin/64bit/obs64.exe`。

> 注：本仓库的 `plugins/CMakeLists.txt` 中 `frontend-tools` 与 `win-dshow` 两个插件被移出构建（本地改动，与本功能无关）。

## 主要新增/修改文件

| 文件 | 说明 |
| --- | --- |
| `plugins/win-capture/region-capture.c` | 绘制区域源实现 + proc 接口 |
| `plugins/win-capture/region-picker.{c,h}` | 全屏框选选择器 |
| `plugins/win-capture/plugin-main.c` | 注册源与 proc |
| `frontend/widgets/FloatingBall.{hpp,cpp}` | 悬浮球、可调整区域框、区域录制流程 |
| `frontend/widgets/OBSBasic.{hpp,cpp}` | 画布跟随场景管理器 |
| `frontend/settings/OBSBasicSettings.cpp` + `frontend/forms/OBSBasicSettings.ui` | 悬浮窗开关设置项 |
| `plugins/frontend-tools/auto-cleanup.{hpp,cpp}` | 录制后自动清理：删除短视频与原始格式文件 |
| `plugins/frontend-tools/auto-cleanup-dialog.{hpp,cpp}` | 自动清理设置对话框 UI |
| `plugins/win-capture/data/locale/*.ini`、`frontend/data/locale/*.ini` | 中英文词条 |

### 插件对外的 proc 接口

- `win_capture_region_picker_select` —— 弹出全屏框选，返回显示器 ID 与区域坐标；
- `win_capture_region_clamp_to_monitor` —— 把绝对坐标矩形映射到所在显示器并裁剪。
